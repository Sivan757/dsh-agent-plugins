# Docs

- [Specification](https://agent-plugins.org/specification) — Agent Plugins v1, the format every suite here conforms to.
- [dsh-agent-plugins-market](https://github.com/Sivan757/dsh-agent-plugins-market) — the installer plugin that scans, installs, and mounts these suites; its `docs/reference/dsh-plugin-development-standard.md` covers the market plugin itself.
- [com.deepseek.harness namespace](https://github.com/Sivan757/dsh-agent-plugins-market/tree/dev/schemas/com.deepseek.harness/spec.md) — the namespace contract used for commands, agent roles, hooks, and LSP declarations.
- Vendored schemas: [plugin.schema.json (1.0.0)](https://github.com/agentplugins/agent-plugins-spec/tree/main/schemas/1.0.0), [mcp.schema.json (1.0.0)](https://github.com/agentplugins/agent-plugins-spec/tree/main/schemas/1.0.0).
